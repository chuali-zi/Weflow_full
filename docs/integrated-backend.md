# WeFlow 本地解密接入说明

本分支基于 WeFlow 5.0.0（上游提交 `837697b`）。保留原 Welcome、设置、聊天和导出界面及用户流程，通过 Electron 现有密钥和 WCDB 接口接入仓库内的 wxtext 解密工具与查询后端。

## 用户操作流程

```text
WeFlow 原欢迎/数据库设置界面
  → 原“自动获取密钥”按钮
  → 按各数据库首页认证密钥，并校正账号数据目录
  → 用户从系统托盘正常退出微信
  → 原“连接数据库”操作
  → 复制源数据库与 WAL、认证解密成本机只读副本
  → 原聊天界面查询副本
```

没有增加准备页、首页更新按钮或新的连接流程。Welcome 页面继续使用原来的目录输入、密钥获取按钮、连接按钮和错误提示。密钥获取成功时，后端返回的已认证数据根路径回填到原路径输入框；若显式选择的目录与当前微信进程不匹配，错误信息保留错误码、建议路径和下一步提示，用户可在原输入框修正目录。

密钥按数据库分别验证和缓存，不把联系人库密钥套用于所有分库。Windows 下会比较发现到的同账号目录，通过数据库首页 HMAC 认证确认哪个目录与当前运行微信相符；只有唯一匹配时才自动校正。若有多个目录均可认证，则提示用户在原路径栏选择，避免猜测。

用户登录微信并点击原有密钥按钮后，点击原有的“连接数据库”操作。首次连接，或检测到源数据库 / WAL 元信息变化时，连接检查会进入副本准备；如果微信仍在运行，会提示用户从系统托盘菜单正常退出，再次点击原有连接操作。后端确认微信进程已退出后，复制所需数据库及 WAL，合并已提交 WAL，再按每个数据库自己的密钥认证和解密。全部目标数据库成功后才切换活动副本；失败时保留旧副本。准备后由原 WeFlow WCDB 调用入口打开只读副本，后续聊天查询继续沿用原界面。

副本模式不监控微信实时写入。WeFlow 原有连接检查会比较源数据库和 WAL 的元信息：未变化时复用完整副本；发现变化时进入更新流程，按提示退出微信并再次连接。更新完成前旧有效副本仍保留。源数据库以只读方式访问和复制，解密操作写入单独的应用数据目录。副本为明文 SQLite，密钥缓存由 DPAPI 保护。

## 组件选择与边界

- **密钥工具**：原设置中显式配置了第三方密钥获取 `.exe` 时，WeFlow 继续调用该程序；未配置时调用内置 wxtext。若配置路径无效，向用户返回配置错误，不静默改用另一实现。
- **WCDB 查询**：原设置中显式配置了第三方 WCDB DLL 时，继续走原生 WCDB Worker；未配置时由本地 Python 查询后端实现 WeFlow Worker 的消息协议。
- **原始导出**：已配置 WeLive 导出 `.exe` 时，沿用原配置；未配置且内置原始导出可用时输出 JSONL，并由 WeFlow 原有格式转换器生成其支持的格式。
- **离线核心范围**：联系人、会话、完整消息分库、消息分页和搜索、发送者识别、Zstandard 长文本及基础统计。
- **尚未完整接入或验证**：图片 AES 密钥自动获取、完整群成员名单、朋友圈专用查询、部分高级报表和媒体附件恢复。实时监听与数据库写操作不属于离线副本实现范围。

Windows x64 与 wxtext 支持的微信 4.x SQLCipher 4 / 4096 字节页格式为实现目标。微信 4.1.13.65 的目录选择和数据库首页密钥认证已有真实环境结果，完整数据库快照与聊天导出仍待验证；其他微信版本兼容性也尚未确认。

## 实现位置

- `python/wxtext/`：密钥扫描、密钥校验、DPAPI 缓存、数据库复制、WAL 处理与认证解密。
- `python/weflow_backend/`：账号目录匹配、快照管理、只读 SQLite、WeFlow 会话/消息查询及内置原始导出。
- `electron/services/keyProviderService.ts`：优先使用用户配置的外部密钥程序；未配置时调用内置后端。
- `electron/services/wcdbService.ts`：按现有 WCDB 配置选择原 Worker 或内置查询 Worker。
- `electron/localWcdbWorker.ts`：内置后端的原 WCDB Worker 消息协议适配。
- `electron/services/integratedService.ts`：本地后端客户端与 Electron IPC 支持。
- `scripts/launch.ps1`：源码运行环境准备及启动。

运行状态和密钥缓存位于 `%APPDATA%\WeFlow-full\backend`。加密源数据库不会在原路径修改；明文快照和临时数据保存在本机应用数据目录。成功创建新快照后才更新活动副本，失败不会覆盖旧副本。历史快照目前保留，频繁准备大型账号时应留意磁盘空间。

## 验证说明

真实微信 **4.1.13.65** 账号的密钥认证已验证：微信配置指向的 D 盘目录中 **21 / 21** 个数据库首页通过 HMAC 认证，旧 C 盘目录中 **0 / 18** 个通过。独立打包后端按微信配置自动选中 D 盘，缓存的 **21** 个逐库密钥均通过对应首页认证。这证明目录选择与密钥认证链路工作，不代表数据库已整体解密。

**13 项后端回归测试**已通过，使用合成数据库覆盖密钥认证、分库、分页、发送者、长文本、搜索、只读查询、导出及失败恢复。源代码和独立打包 Electron 均使用合成账号通过 WeFlow 原界面、连接、分页、搜索和 TXT、HTML、CSV、JSON 导出流程。上述桌面结果不代表真实聊天内容已导出。

真实账号的完整数据库快照和聊天导出尚未完成，因为测试时真实微信仍在运行。正常退出微信后，仍需实测原连接操作触发的副本准备、整库认证解密、WeFlow 聊天查看及真实导出；根任务会继续执行这部分验证并补充结果。
